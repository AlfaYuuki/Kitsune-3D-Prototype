# 🦊 Kitsune FunZone 3D

**Explore. Battle. Discover. Become a legend.**

A browser-based 3D RPG adventure by **Alfa Yuuki**, built with JavaScript and Three.js.

## 🌸 About

Explore a fantasy world filled with spirits, quests, hidden treasures, and fox companions. Discover new regions, challenge powerful guardians, and build your collection.

## ✨ Features

- 🌍 Explore the valley and four expanded regions.
- 👹 Battle regional spirit bosses with unique encounters.
- ⚔️ Fight using attacks, dodges, and character abilities.
- 💎 Collect weapons, accessories, crystals, and treasures.
- 📜 Complete quests and track your progress.
- 🦊 Discover fox companions.
- 🏯 Visit Kitsune Village, its shrine, shop, and rest area.
- 🗺️ Use the world map and fast travel.
- 📱 Play on desktop or Android with adjustable graphics settings.
- 💾 Save progress using supported browser storage.

## 🗺️ World Regions

| Region | Guardian |
| --- | --- |
| 🎋 Bamboo Hollow | Bamboo Guardian |
| 🍁 Maple Ridge | Crimson Kitsune |
| 🌫️ Mistwater Marsh | Mist Wraith |
| ❄️ Frostpeak Pass | Frost Oni |

Each region has its own environment, spirits, treasures, and exploration rewards.

## 🎮 Controls

### Desktop

| Action | Control |
| --- | --- |
| Move | `W A S D` / Arrow Keys |
| Run | `Shift` |
| Rotate camera | Mouse drag |
| Zoom | Mouse wheel |
| Attack | `Space` / Click |
| Interact | `E` |
| Use potion | `H` |
| Dodge | `V` |
| Bag | `I` |
| Shop | `B` |
| Quests / World Map | `Q` |
| Journal | `J` |
| Fox companions | `C` |
| Domains | `G` |
| Anahita ability | `R` |
| Demiurge ability | `F` |

### Mobile

Use the on-screen joystick and action buttons to move, attack, dodge, interact, and use abilities.

## 🚀 Run Locally

```bash
git clone https://github.com/AlfaYuuki/Kitsune-3D-Prototype.git
cd Kitsune-3D-Prototype
```

Open `index.html` in a modern browser. An internet connection is required for Three.js modules loaded from public CDNs.
