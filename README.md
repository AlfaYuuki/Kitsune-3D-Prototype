## 🌸 About the Game

Step into a fantasy world filled with spirits, hidden treasures, quests, and fox companions. Explore mysterious regions, challenge powerful guardians, collect equipment, and uncover everything the world has to offer.

**Kitsune FunZone 3D** is an evolving browser-based RPG prototype built with HTML, CSS, JavaScript, and Three.js.

## ✨ Features

| Feature | Description |
| --- | --- |
| 🌍 **World Exploration** | Explore the valley and four expanded regions. |
| 👹 **Guardian Bosses** | Challenge powerful regional spirits with unique encounters. |
| ⚔️ **Combat** | Fight spirits, dodge attacks, and use character abilities. |
| 💎 **Equipment & Loot** | Discover weapons, accessories, crystals, and treasures. |
| 📜 **Quests & Journal** | Follow objectives and track your adventure. |
| 🦊 **Fox Companions** | Meet and bring fox companions along. |

| 💾 **Save Support** | Keep progress where supported by the browser. |

## 🗺️ World Regions

The v6.7 **Expand the World** update introduced four explorable regions beyond the original map.

| Region | Location | Spirit HP | Damage Multiplier |
| --- | --- | ---: | ---: |
| 🎋 **Bamboo Hollow** | South of the meadow | 70 | ×1.25 |
| 🍁 **Maple Ridge** | East, along the river's south bank | 95 | ×1.45 |
| 🌫️ **Mistwater Marsh** | West, along the river's south bank | 120 | ×1.65 |
| ❄️ **Frostpeak Pass** | North, past the arena | 150 | ×1.9 |

Each region features its own environment, five regional spirits, a hidden chest, a waypoint stone, a first-entry reward, and a region banner.

Other v6.7 additions include the location HUD, World Map in the Quests tab, fast travel, four new legends, and adaptive scenery detail. The original six-chest quest and legend continue to track the original six chests.

## 🎮 How to Play

Launch the [live game](https://alfayuuki.github.io/Kitsune-3D-Prototype/) in a modern browser and wait for the world to load.

### Desktop Controls

| Action | Control |
| --- | --- |
| Move | `W A S D` or Arrow Keys |
| Run | `Shift` |
| Rotate camera | Drag with mouse |
| Zoom camera | Mouse wheel |
| Attack | `Space` or click |
| Interact | `E` |
| Use potion | `H` |
| Dodge | `V` |
| Open bag | `I` |
| Open shop | `B` |
| Open quests / World Map | `Q` |
| Open journal | `J` |
| Open fox companions | `C` |
| Open domains | `G` |
| Anahita ability | `R` |
| Demiurge ability | `F` |

### Mobile Controls

Use the on-screen joystick to move and the action buttons to attack, dodge, interact, use potions, and activate available abilities. The layout adapts to the screen size and game state.

## 🚀 Run Locally

You can run the browser prototype locally without installing a package manager.

```bash
git clone https://github.com/AlfaYuuki/Kitsune-3D-Prototype.git
cd Kitsune-3D-Prototype
```

Open `index.html` in a modern browser, or serve the project folder with a local static web server.

> An internet connection is required for the Three.js modules loaded from public CDNs.

## 🛠️ Troubleshooting

- **Stuck on loading:** Check your internet connection and reload the page.
- **Old version appears:** Refresh the page. If needed, use the in-game **Clear cache & reload** option when available.
- **Low performance:** Close other heavy apps or browser tabs and try a lower graphics setting.
- **Mobile controls feel awkward:** Try rotating your device or adjusting the browser view.
